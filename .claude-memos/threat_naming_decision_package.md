# #26 결정 패키지 — §5.1 위협 명명: 헤더 `[15:12]` CRC-4 · CHKSUM EH 보류의 선행 조건 해소

## 0. 전제 — 검증 계보와 기전 축 교체

- 이 패키지는 세 갈래 작업(경계갈래·의무행렬·채택평가)의 **적대 검증을 통과한 문면만** 싣는다. 검증이 반례를 든 문장(링 호스트-상주 전제, 태그 물리 확폭, 「한계 기여 0」 조합 기각 논거, C=0 계수 등)은 전부 수리된 형태다.
- **기전 축은 배경 메모 §8.9–§8.11 (2026-08-28, 검증 이후 착지)이 대체한다** — 메모 자신의 지시다(§8.9 말미). CHKSUM *EH* 는 **CH (Castagnoli Header)** 로 재정의됐다: word1 고정 1워드, 32비트 전부 CRC-32C(0x1EDC6F41), **EH 가 아니다** — EH 회계·코드점(`0xA`–`0xE`)·반복 규약 어디에도 계상되지 않는다. 이로써 검증이 든 실측 반례 「W4 후 0x79 FMINMAX 4/4 슬롯 사슬에서 CHKSUM 이 원리적으로 못 탄다」(`wt64v1-lf64di.md:136,295-300`)는 **구성적으로 소멸**한다. 경계·의무 축은 검증 통과분 그대로다.
- **CRC-32C 검출력을 이 세션에서 실측했다**: 부호어 448b(최대 명령 416b + CH 32b)에서 가중 1·2·3·4·5 부호어 **0건**, 가중 6 부호어 실재 — **HD = 정확히 6, 즉 5비트 이하 훼손 전부 검출.** §8.9 가 「외부 지식, 원전 핀 권장」으로 남긴 주장이 실측으로 핀됐다. HD=8@≤177b 구간 주장은 재지 않았다(② 원전 핀으로 이관).
- **의무 칸 계수 규칙** (의무행렬 수리 반영, 이 전제 없이는 갈래 간 비교 불가): *채택된 방어의 부류-수준 잔여 수용은 적법한 폐쇄다; 방어가 원리적으로 닿지 않는 표면의 필드-수준 수용은 명명의 공동화다.* 칸 수는 「수용-문면 부담」 계수다.
- 이미 채택된 **W5 (OPREF `[23:20]` CRC-4)** 는 이 결정과 무관하게 선다 — 정당화 축이 §5.1 이 아니라 §1.4.6 국소 검산(조용한 오독 닫기)이다. 어느 갈래에서도 불변.

## 1. 갈래 요약표

| 갈래 | 문면 한 줄 | 의무 칸 | 보류 둘의 처분 | 되돌림 |
|---|---|---|---|---|
| **A — 부인 명문화** | 「다루지 않는 것」에 *전송·저장 중 비트 훼손(전 표면)* 을 명시 부인 + 만료 함정 | 0 (부인 1항 + 함정 1) | 둘 다 **기각** — 정당화 축 소멸 | §5.1 재개정만으로 부활. 단 T_stable 에 `[15:12]` 동결 → CRC-4 갈래 영구 소멸, 그 후 EH-0 부류는 영구 무방비 |
| **B — 명령 비트열 명명** (권고) | *인코더가 방출한 명령 워드열 ↔ 디코드 경계(§1.6.1) 제시 워드열의 불일치* — 상주 무관, 봉인→판정 | 신규 의무 0 · **부류-수준 수용 4항** | CHKSUM EH → **CH 로 대체 채택** (#25 W8); 헤더 CRC-4 → **기각** (EH-0 축 한정 재소환 조건 명기) | 명명은 pre-stable 개정으로 가역. CH 재인코딩은 매몰이나 `[15:12]` 온존(4b 자유)이라 C 축 선택지가 stable 까지 보존된다 |
| **C — 협소 명명 (word 0)** | *기본 헤더의 훼손*만 명명, 방어 = `[15:12]` CRC-4 | **5 (필드-수준) + 2** | 헤더 CRC-4 **채택**; CH **안 함** (§8.10 회귀 행) | **최악** — word 0 마지막 예비 소진 + 기존 바이너리 전량 재인코딩·truth table 재캡처, 플래그 성장 여지 소멸 |
| **D — 광의 명명 (전 표면)** | 명령 + 페이로드 + 태그 + CTRL 사이드밴드 + MMIO + 완료 전부 명명 | **11** | 둘 다 채택 + 신기전 다수 강제 | — (기각 기록만 남긴다) |

**회색 지대 판정** (경계가 실제로 그어지는가를 실물로 확인한 여덟):

1. **조각 머리 CTRL 채널 (E.10)** — B·C 의 객체 **밖**, 명시 제외 필수. 장치 저작 사이드밴드(`e-defined.typ:1421-1474`)·디코드 판정 이후 생성·on-die. 순번 훼손은 loud(도착 시 중복·초과 판정 + 종료 시 집합 등식, `04-ext-payload.typ:237-247`); 조용 잔여는 상보 쌍대 교환뿐 — **재지 않았다**. 단 W4 후 **선언 총개수가 이중 거처**가 된다(ACCTGT `[23:16]` 은 CH 가 덮고, CTRL 사본은 밖) — 경계가 한 논리 선언의 가운데를 지나며, authority/검산 관계는 B.5 미결 행 「조각열 총개수의 *두 거처* — authority 와 방어 비대칭」(`b-gaps.typ:1227-1246`)이 진다 — 선언 자리 행 자체(`:1212-1225`)는 W4 로 *해소*됐고, 두 거처 관계만 미결로 남아 별도 행이 됐다.
2. **SD_BODY 주소·SD 태그 워드** — 봉투 축, **밖**. 봉투 훼손으로 *무결한 다른 내용물*이 제시되면 CH 도 원리상 못 잡는다(자기 일관). 명명의 객체를 「비트열 불일치」(객체·구간)로 못박아야 이 축이 디스크립터 봉투(D 전용)로 밀린다 — 봉투/내용물 분리는 정본 문면이 받친다(`e-defined.typ:504-515`, fault `[18]`).
3. **링의 거처** — **미결이다** (`e-defined.typ:639-651`, B.5 등재). 「호스트 상주가 규범」은 거짓(검증 F1) — 명명의 근거는 *상주가 미결이므로 어느 결정에도 견디는 상주-무관 end-to-end 검사*다.
4. **PORT `dest_node_id` 16b** (§1.4.1 `01-isa-asm.typ:532-587`; 「16비트 전체가 하나의 `dest_node_id` 다」는 `:582`) — C 의 반례. 사상된 *다른* 노드로의 1비트 훼손 = 조용한 오배달, word 0 밖·W5 밖·구조 검산 무반응. 「조향 워드만 명명」 근거가 가장 조향적인 필드를 경계 밖에 둔다. B 에서는 안(CH 가 덮는다).
5. **태그 예약 10b** — D 전용 회색. CRC-8 이 폭 대가 없이 앉지만(`01-isa-asm.typ:1184-1185`) 태그는 홉마다 장치가 재저작(`:36`)하므로 검사 주체 = 저작 주체 — 자기 일관 논증이 전 홉 성립, 보호 구간이 on-die SEU(= config 메모리, 별개 설비)로 퇴화. 게다가 「사이드밴드 통짜 태그에 별도 검사 지점을 두지 않는다」(`:1194-1195`) 규범 개정이 셋째 선행.
6. **sub-word 거절** — 이행 지점이 호스트 버스 어댑터로 문서 경계 밖, **미측정**(`03-hiu.typ:1267`). 모든 초안에 단서 병기. 스테이징·한-워드 전이(`e-defined.typ:1272-1276`)는 실물.
7. **IMM32/64 w0 `[31:16]`** — 측정 트랙 미기재. **재지 않았다** — per-EH 니블 갈래 부재 진술에서 제외.
8. **EH-0 부류 (NOP — ISA 전수에서 유일 `required=[]`)** — B 의 수용 1항이자 C 의 CRC-4 만 닿는 유일 표면. 훼손 양방향(무위→실연산·실연산→무위) 전부 조용. #24 Ctrl 이 부류를 늘릴 수 있다.

## 2. 갈래별 §5.1 개정 초안 전문

### 갈래 A — 부인 명문화 (실행 가능)

```typst
#규범(라벨: "범위")[
  이 장이 다루는 것:
  + *테넌트 간 정보 누출* — 같은 장치를 나눠 쓰는 파티션 사이
  + *주소 관측을 통한 추론* — 장치가 만드는 접근 패턴에서 정보를 얻는 것
  + *타이밍 채널* — 처리 시간의 차이에서 정보를 얻는 것 @kocher_timing @bernstein_cachetiming

  이 장이 다루지 않는 것: 물리적 공격, 공급망, 호스트 측 취약점, 그리고
  *전송·저장 중 비트 훼손* — 명령 워드열, 페이로드, 태그, 사이드밴드,
  MMIO 기입, 완료 방향 전부. 이 부인은 누락이 아니라 결정이다. 잔여는
  이 문서 밖의 방벽(PCIe LCRC · 호스트 ECC)과 이 문서의 구조 검산
  (@sec:extpayload 4.2.2 — 선언과 실물의 자기모순만 잡는다), 그리고
  @sec:isa 1.4.6 국소 검산이 덮는 만큼만 덮이며, 그 밖은 수용한다.
]

#함정(라벨: "이 부인에는 만료가 걸려 있다")[
  기본 헤더 `[15:12]` 는 stable 동결과 함께 영구히 예약 0 이 된다. 그날
  이후 이 부인을 뒤집어 명령 비트열 훼손을 명명하더라도, EH 없는 명령 —
  전 비트가 조향 비트인 부류 — 를 덮을 도구는 남아 있지 않다. 후보가
  CH 하나로 좁혀져 있고, 그것이 구조상 못 덮는 끝이 정확히 그 부류다.
  이 부인을 무비용으로 뒤집을 수 있는 마지막 시점은 stable 이전이다.
]
```

### 갈래 B — 명령 비트열 명명 (실행 가능, 권고 형태 = CH EH-조건부 기준)

```typst
#규범(라벨: "범위")[
  이 장이 다루는 것:
  + *테넌트 간 정보 누출* — 같은 장치를 나눠 쓰는 파티션 사이
  + *주소 관측을 통한 추론* — 장치가 만드는 접근 패턴에서 정보를 얻는 것
  + *타이밍 채널* — 처리 시간의 차이에서 정보를 얻는 것 @kocher_timing @bernstein_cachetiming
  + *명령 비트열의 훼손* — 인코더가 방출한 명령 워드열과 디코드 경계
    (@sec:isa 1.6.1)에 제시된 워드열의 불일치. 구간은 봉인부터 판정까지이고,
    원천 — 호스트 메모리, 버스, on-die 전송 — 을 구별하지 않는다. 링의
    거처가 미결이므로(@sec:defined E.5 함정 · @sec:gaps B.5) 검사도 거처에
    무관해야 한다.

  이 장이 다루지 않는 것: 물리적 공격, 공급망, 호스트 측 취약점. 4항의
  객체에 대해서는 추가로 — 페이로드, 태그(디스크립터의 태그 워드 포함),
  MMIO 기입, 완료 방향, 조각 머리 채널(@sec:defined E.10), 그리고 디스크립터
  훼손으로 *무결한 다른 워드열*이 제시되는 것. 4항의 객체는 내용물의
  불일치이지 봉투가 아니다 (@sec:defined E.5.4 해설 — 봉투는 드라이버
  코드가 고치고 내용물은 컴파일러 출력이 고친다).
]

#해설(라벨: "왜 이 경계인가 — 조용한 표면이 정확히 이것뿐이다")[
  제외한 표면의 훼손은 이미 loud 이거나 이 문서 밖 방벽의 몫이다. 조각
  머리의 순번 훼손은 도착 시점의 중복·초과 판정과 종료 시점의 집합 등식이
  잡고(@sec:extpayload 4.3), 봉투의 결함은 접수면 판정이 잡으며(@sec:defined
  E.5.4), MMIO·완료 방향과 호스트 메모리는 PCIe LCRC 와 호스트 ECC 의
  몫이다. 명령 워드열만이 다르다 — 구조 검산은 선언과 실물의 자기모순을
  잡으므로, *적법한 필드 안의 값이 다른 적법한 값으로 뒤집히는* 훼손은
  어떤 검사도 울리지 않고 조용히 다른 연산이 된다. 부분 기입은 스테이징과
  한-워드 전이가 덮으나(@sec:defined E.7), sub-word 거절의 이행 지점은
  호스트 버스 어댑터로 이 문서의 경계 밖이며 미측정이다(@sec:hiu 3.9).
]

#규범(라벨: "잔여 수용 — 부류 전수, 넷으로 닫힌다")[
  4항의 방어 기전(@sec:isa 1.3.1 의 CH)이 닿지 않는 잔여는 다음 네 부류이며,
  이 명명은 그것을 명시적으로 수용한다:
  + *EH 없는 명령* — CH 의 존재는 next_hdr 에서 유도되므로 EH 0 인 명령
    (현행 ISA 전수에서 NOP 하나)은 덮이지 않는다. 훼손은 양방향 모두 조용하다.
  + *검출 한계 통과* — 부호어 448비트에서 5비트 이하 훼손은 전부 검출된다
    (HD 6 — 실측). 그 이상의 상관 훼손은 $2^(-32)$ 잔여로 조용하다.
  + *봉인 이전 훼손* — 틀린 비트열을 봉인하면 CRC 도 그 비트열의 것이다.
    호스트 SW 의 버그는 4항의 대상이 아니라 「호스트 측 취약점」 부인의
    대상이다.
  + *조각 머리 채널의 총개수 사본* — 선언 총개수는 ACCTGT `[23:16]`(CH 가
    덮는다)과 각 조각의 CTRL 사이드밴드(@sec:defined E.10 — 덮지 않는다)
    양쪽에 실린다. 사이드밴드 쪽의 조용한 잔여는 상보 쌍대 교환뿐이며 그
    확률은 재지 않았다. 두 거처의 authority 관계는 @sec:gaps B.5 미결이다.
]

#함정(라벨: "명명과 기전 사이의 창 — 그리고 만료가 하나 있다")[
  이 개정이 서는 순간부터 기전이 착지할 때까지 명령 비트열은 「명명된 위협,
  방어 없음」 상태다. 그 구간은 명시적 잔여 수용이며 폐지 시한은 인코딩
  개정 파도다 — 이 개정과 그 파도의 W-항 등재는 같은 개정에서 한다.

  잔여 수용 1항에는 만료가 걸려 있다. 그 부류를 덮는 유일한 도구는 기본
  헤더 `[15:12]` CRC-4 인데, stable 동결과 함께 그 갈래는 영구 소멸한다.
  그 전에 보호 필요 판정이 서지 않으면 1항은 *영구* 수용이 된다. 신규
  확장(Ctrl 류)이 EH 없는 명령을 늘리면 1항의 폭이 함께 는다 — 그 확장의
  설계 입력이다.
]
```

(형태 갈래에 따른 초안 변화 — Q2 의 함수: **always-on** 이면 수용 1항과 함정 둘째 문단 삭제; **F_CH** 면 1항이 「비장착 명령」으로 바뀌고 「플래그 1→0 소등 — CH 워드의 사슬 독으로 대개 loud 이나 보장 없음」 수용이 추가된다.)

### 갈래 C — 협소 명명 (실행 가능)

```typst
#규범(라벨: "범위")[
  이 장이 다루는 것:
  (1·2·3항 현행 그대로)
  + *기본 헤더의 훼손* — 인코더가 방출한 word 0 과 디코드 경계
    (@sec:isa 1.6.1)에 제시된 word 0 의 불일치. 방어는 `[15:12]` CRC-4
    (@sec:isa 1.3.1 개정 — $x^4+x+1$, 부호어 32b: 1비트 전부·버스트 4 이하
    전부 검출, 2비트는 496쌍 중 19쌍 미검출, 랜덤 잔여 6.25%)다.
    처분은 malformation + loud, 판정은 디코드 경계다.

  이 장이 다루지 않는 것: 물리적 공격, 공급망, 호스트 측 취약점, 그리고
  word 0 밖의 모든 비트 훼손 — EH 워드, 페이로드, 태그, 사이드밴드,
  MMIO 기입, 완료 방향.
]

#함정(라벨: "이 경계는 방어 수단의 모양대로 그어져 있다")[
  최대 13워드 명령에서 명명이 덮는 것은 1워드다. 「조향 워드의 훼손만이
  조용히 다른 연산이 된다」는 근거에는 반례가 실재한다 — PORT 의
  dest_node_id 16비트(@sec:isa 1.3.2)는 사상된 다른 노드로의 1비트 훼손이
  조용한 오배달이 되는, 이 기계에서 가장 조향적인 필드이고, word 0 밖이다.
  그리고 이 채택은 「기존 바이너리는 한 비트도 안 바뀐다」로 산 것을 도로
  판다 — 전량 재인코딩·재캡처가 부활하고, word 0 의 마지막 예비 4비트가
  소진되어 플래그 성장 여지가 사라진다.
]
```

### 갈래 D — 광의 명명 (기록 문면 — 채택 불가의 기록)

```typst
#함정(라벨: "광의 명명은 검토됐고 기각됐다 — 이 기록이 그 재검토를 막는다")[
  「전송·저장 중 비트 훼손」을 전 표면 — 명령, 페이로드, 태그, 조각 머리
  사이드밴드, MMIO, 완료 방향 — 에 걸쳐 명명하는 갈래는 수용-문면 부담
  11칸을 만들고, 그중 정본이 완결할 수 있는 것은 명령 축 하나다:

  + *태그* — 예약 10비트에 CRC-8 이 폭 대가 없이 앉는다(@sec:isa 1.3.2).
    그럼에도 서지 않는다: 태그는 홉마다 장치 자신이 재저작하므로
    (@sec:isa — 명령어가 태그를 만들고 그 태그가 다음 홉의 입력이 된다)
    검사 주체와 저작 주체가 같고, 자기 일관 쓰레기 논증이 전 홉에서
    성립한다. 보호 구간은 on-die 홉 간 전송으로 퇴화하며, FPGA 에서 그
    축의 실물은 config 메모리 — 별개 설비다. 나아가 「사이드밴드의 통짜
    태그에 별도 검사 지점을 두지 않는다 — 검사가 두 곳이면 드리프트한다」
    (@sec:isa 1.4.4 계열 규범)의 명시적 개정까지 선행으로 요구한다.
  + *페이로드* — beat 64비트에 여유 비트 0 (실측). beat 당 CRC-8 은 대역
    12.5% 를 태우고, 값 훼손이 조용한 자리와 검사가 앉을 자리가 어긋난다.
  + *조각 머리 사이드밴드* — 장치 저작이라 인코더 봉인의 객체가 아니고,
    순번 훼손은 이미 loud 다(@sec:extpayload 4.3 — 도착 중복·초과 판정 +
    종료 집합 등식). 조용한 잔여는 상보 쌍대 교환뿐이며 재지 않았다.
  + *MMIO 기입 · 완료 방향 · 호스트 상주 구간* — PCIe LCRC 와 호스트 ECC
    의 몫이고, 호스트 SW 버그는 어떤 CRC 로도 못 잡는다(같은 SW 가 CRC 도
    계산한다).

  명명의 의무 아래서 이 갈래는 「명명된 위협, 방어 없음」 11면을 만들거나
  위 신기전 전부를 강제한다. 어느 쪽도 감당하지 않는다.
]
```

## 3. 권고

**갈래 B + 기전 CH(EH-조건부 형) — §5.1 개정과 #25 W-항 등재를 같은 개정에서.**

보류 둘의 처분:

- **CHKSUM EH** — 그 형태로는 소멸, **CH 로 대체 채택**. #25 W-목록에 **W8** 신설: 「CH (Castagnoli Header) — word1 고정 1워드, 32b 전부 CRC-32C(0x1EDC6F41), 존재는 next_hdr ≠ END 에서 유도(새 비트 0), EH 아님(회계·코드점·반복 규약 무관), bh_len 에는 포함, 처분 malformation + loud, 판정은 디코드 경계」. ② 잔여로 이관: 메시지 비트 순서·init 명세 못박기 · HD=8@≤177b 원전 핀 · CH 자기 워드 제외 규칙 문면.
- **헤더 `[15:12]` CRC-4** — **기각.** always-on 이면 CH 가 word 0 을 HD 6 으로 덮어 잉여, EH-조건부에서도 잔여가 EH-0 부류 하나로 좁혀지는데 그 보호를 위해 word 0 마지막 예비 + 전량 재인코딩 + 플래그 성장 여지를 지불하는 것은 Q2-③ 으로만 정당화된다. 기각 문면에 재소환 조건을 명기한다: 「EH-0 부류의 보호 필요 판정이 stable 이전에 서면, 그 자리의 도구는 이것이다」(§8.7). `[15:12]` 는 4b 자유 — **즉시 배정 없음, 기본값 용도 = 플래그 성장 여지** (§8.10 기채택).

근거:

1. **명명의 의무가 실제로 닫힌다.** B 는 방어 범위 = 명명 범위인 유일한 갈래이고(계수 전제 명시 하에 신규 의무 0), 잔여가 부류-수준 4항으로 전수 폐쇄된다. A 는 정직하나 만료 후 전 축 영구 무방비, C 는 5칸 + dest_node_id 반례, D 는 11칸.
2. **상주-무관 논증이 참인 형태로 선다.** 링 거처는 미결(B.5)이고 #27 로 wire 구간이 더해진다 — 봉인→판정 end-to-end 는 어느 거처 결정에도 견딘다.
3. **EH-조건부는 opt-in 반론(§8.3 「끌 수 있는 검사는 검사가 아니다」)을 구조로 소거한다** — 작성자 선택이 없는 결정론적 규칙이고, 존재 신호(next_hdr)가 bh_len↔END 삼중 검산에 이미 얽혀 있어 단독 비트 소등이 없다. §8.7 의 발견 순환도 없다(위치 word1 고정 + 유도 존재).
4. **검출력이 실측으로 선다** — HD 6 @ 448b(이 세션 측정), 랜덤 잔여 2⁻³². CRC-16 안(HD 4)·CRC-8 안(주기 127 < 4워드)을 지배한다.
5. **되돌림 지형이 최선이다** — `[15:12]` 온존으로 C 축 선택지가 stable 까지 살아 있고, CH 는 코드점을 안 먹어 EH 카탈로그 빈칸 다섯이 그대로 남는다.

파이프라인 영향:

- **#25**: W8 등재 + 부속 — §1.3.1 개정(word1 규범·「둘째 헤더」 용어 한 줄), **EH 있는 전 명령의 bh_len 변경 → 기존 바이너리 전량 재인코딩·truth table 전량 재캡처**(W1~W7 재측정과 같은 파도에서 한 번), GUARD-MAP 신설 가드(CH 판정), 어셈블러 encode_pass(CH 합성), SEC-7 논증 불변(`[15:12]` 는 계속 0·마스킹 유지), fp ROM 게이트 무관.
- **#24**: 신규 확장의 명령·신규 EH 종류는 명명 경계 안에 **자동 편입**된다(명령 비트열이므로 CH 가 통째로 덮는다 — per-EH 검산 불요). 단 **Ctrl 류가 EH-0 명령을 늘리면 수용 1항의 폭이 는다** — #24 설계 입력으로 명시(EH-0 으로 설계할지가 이제 보안 결정이다).
- **#27**: 불변 + **접면 단순화** — CH 는 통째로 wire 밖(ingress 재계산·재부착)이고 존재가 wire 의 next_hdr 에서 유도되므로 envelope 신호 불요, 예약 2비트 온존, 0-낭비 유지.
- **W5**: 공존, 불변(축이 다르다 — §1.4.6).
- **B.5**: 「조각열 선언 총개수의 선언 자리」 행에 하위 항 추가 — CH 채택 후 ACCTGT 사본은 덮이고 CTRL 사본은 안 덮이는 이중 거처의 authority 관계.

## 4. 사용자에게 물을 것 — 셋

**Q1. 경계를 긋는가, 부인을 명문화하는가 — A 대 B.**
- A: 한 문장으로 전 표면을 정직하게 닫는다. 귀결 — stable 동결과 함께 명령 축 포함 전부가 *영구* 무방비가 되고, 그 사실을 함정으로 안고 산다.
- B(권고): 조용한 표면 하나를 명명하고 CH 로 닫는다. 귀결 — 재인코딩 파도 1회(#25 에 합류, 재검증은 한 번) + EH-0 부류의 명시 수용.

**Q2. B 라면 — EH-0 부류(NOP·미래 Ctrl)의 처분.** (§8.11 의 넷 중 F_CH 는 검증에서 열세 — 실질 셋)
- ① EH-조건부 + 명시 수용(권고): 비용 최소(NOP 무변경), 귀결 — 조향 밀도 최고 부류의 잔여가 stable 에 영구화된다.
- ② always-on: 잔여 소멸·존재 비트 불요, 귀결 — 전 명령 +1워드(NOP 2배, 최대 14워드)와 NOP 포함 전량 재캡처.
- ③ EH-조건부 + 헤더 CRC-4 병행(§8.7 길이 분담): EH-0 끝을 CRC-4 가 덮는다, 귀결 — word 0 마지막 예비 소진 + `[15:12]` 재인코딩 부활 + 플래그 성장 여지 영구 소멸.

**Q3. 명명과 기전의 동시성.**
- 같은 개정에서 §5.1 + W8 등재(권고): 「명명된 위협, 방어 없음」 창이 문면상 잔여 수용으로만 존재한다.
- 명명 선행: #26 이 즉시 닫히나, #25 착지까지 명명된 위협이 방어 없이 선다 — 편성문이 경계한 바로 그 형태가 시한부로 성립한다.
